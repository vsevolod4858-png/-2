НОЧНАЯ ВАХТА — Android-проект

Внутри уже находится одиночная версия игры (app/src/main/assets/index.html).
Приложение открывает игру локально в полноэкранном Android WebView; Node.js и сервер не нужны.

Сборка APK через GitHub Actions:
1. Создайте новый пустой репозиторий GitHub.
2. Загрузите в него все файлы и папки из этого проекта (включая .github).
3. Откройте вкладку Actions. При первом запуске подтвердите разрешение на workflows.
4. Запустите workflow "Build Android APK" через Run workflow (или дождитесь сборки после push).
5. Откройте завершённый запуск workflow, внизу раздел Artifacts, скачайте night-watch-debug-apk.zip.
6. Распакуйте архив — внутри будет app-debug.apk. Перенесите APK на Android и установите.

Это debug APK для тестирования/личной установки. Для публикации в Google Play понадобится отдельная release-сборка и подпись.
